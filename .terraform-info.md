# Nota sobre Infraestrutura (Terraform)

⚠️ **A infraestrutura Terraform foi centralizada no repositório `fcg-infra`**

## 📦 Localização

A configuração Terraform para ONG.Donation.Worker está em:
```
fcg-infra/terraform/ong-donation-worker/
```

## 🏗️ Conteúdo

- `data.tf` - Referências a recursos compartilhados
- `identity.tf` - User Managed Identity + RBAC
- `variables.tf` - Variáveis parametrizadas
- `outputs.tf` - Valores de saída
- E mais... (veja README em fcg-infra)

**Nota:** O Worker reutiliza infraestrutura criada por `ong-donation`

## 🚀 Como Usar

### Setup Inicial
```bash
cd ../fcg-infra/terraform/ong-donation-worker
cp terraform.tfvars.example terraform.tfvars
# Editar terraform.tfvars com credenciais Azure
```

### Deploy
```bash
# IMPORTANTE: Primeiro faça deploy de ong-donation!
cd ../ong-donation
terraform apply

# Depois deploy do worker
cd ../ong-donation-worker
terraform init
terraform plan
terraform apply
```
